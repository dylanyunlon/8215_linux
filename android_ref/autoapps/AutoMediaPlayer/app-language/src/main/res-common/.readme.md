### <font color="#77ee77">目录 res-common 说明</font><br/>

- <font color="#00cccc">目录结构</font><br/>
```
src/main/res-common/
    [v] values
    [x] values-zh-rCH
    [x] values-zh-rTW
    [v] ...
    [v] values-ar
    [v] values-fr
    [v] values-ru-rRU
    [v] values-th
    [v] values-uk-rUA
    [v] values-vi
    [v] ...
```

- <font color="#7f7fee">组合规则</font><br/>
```
它与 src/media/res-app 和 src/main/res-pool 组合生成 media-lang-release.aar 模块，提供给主模块使用：
    src/media/res-app/
    src/main/res-common/
    src/main/res-pool/
    
它也可以与 src/skinx/res-$(other)/ 以目录组合的形式被外部扩展皮肤包引用：
    src/main/res-common/
    src/skinx/res-$(other)/
```

- <font color="#ff6f6f">约束禁止</font><br/>
```
明确禁止将简体、繁体资源放到该目录结构中:
src/main/res-common/
    [x] values-zh-rCH
    [x] values-zh-rTW
```
