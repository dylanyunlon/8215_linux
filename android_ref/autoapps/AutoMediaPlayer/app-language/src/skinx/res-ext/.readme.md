### <font color="#77ee77">目录 res-ext 说明</font><br/>

- <font color="#00cccc">目录结构</font><br/>
```
存放扩展皮肤包主题定制语言，可随意发挥：
    [v] res-ext/values-zh-rCN
    [v] res-ext/values-zh-rTW
    [x] res-ext/...
```

- <font color="#ee7f7f">这里只存放扩展皮肤包的中英文语言资源</font><br/>
```
由于扩展皮肤包不容许使用 src/main/res/ 的默认中文资源，所以扩展皮肤包需要单独定义中文；

扩展皮肤包的海外多国语言（非简体、繁体）统一到 src/share/res-common/ 中适配；
```

- <font color="#cc00cc">注意事项</font><br/>
```
组合规则：
    res-ext 与 src/main/res/ 不可共用；
    res-ext 可以与 src/share/res-common、src/share/res-pool、src/skinx/res-ext-pool 组合共用；
```
