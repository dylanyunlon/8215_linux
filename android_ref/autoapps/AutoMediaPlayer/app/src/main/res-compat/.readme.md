### res-compat 是为了兼容不同的产品需求；

- <font color="#00cccc">目录结构</font><br/>
> res-compat/config:
>> 用来对不同主题显示需求做配置；<br>
> 通过这个配置来实现一份代码兼容不同的显示逻辑（运行时读取配置）;<br>
> e.g. 配置简单列表中的信息项是否需要显示 ID3 信息 <br>
>> ```
>> @see StyleX.ListItemType
>> <integer name="simple_list_item_style_type">-1</integer>
>> ``` 
>
> res-compat/share:
>> 目录下的资源是共享资源，多个主题使用同一个资源可以放在这个目录下；<br>
> 中性的资源都可以放到这个目录下（必须），一些多个主题共用的资源也可以放到这里；<br>
> 设计的时候我们需要尽可能的使用共享资源，可以降低包的大小和运行时资源检索效率；

- <font color="#ee5555">资源约束</font><br/>
```
res-compat 目录中禁止存放语言信息：
    语言信息统一在 module:app-language 模块中添加；
```
