### 默认资源目录价

- <font color="#00cccc">目录结构</font><br/>
```
默认的通用资源统一存放在这里：
    res/anim/
    res/drawable/
    res/drawable-mdpi/
    ...
    res/layout/
    res/values/
        [x] string.xml
        [v] $(_other_).xml
    ...
```

- <font color="#ee5555">资源约束</font><br/>
```
res 目录中禁止存放语言信息：
    语言信息统一在 module:app-language 模块中添加；
```
